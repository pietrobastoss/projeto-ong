# ONG Mãos que Transformam

Projeto web desenvolvido para a ONG Mãos que Transformam, com o objetivo de apresentar ações solidárias, projetos, doações e oportunidades de voluntariado.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Git e GitHub

## Funcionalidades

* Navegação responsiva.
* Menu hambúrguer para dispositivos menores.
* Formulário de cadastro com validação.
* Máscaras para preenchimento dos campos.
* Armazenamento de dados utilizando LocalStorage.
* Navegação entre páginas e conteúdos.
* Feedback visual para erros e sucesso.
* Foco visível para navegação por teclado.

## Acessibilidade

O projeto utiliza recursos de acessibilidade, incluindo foco visual nos elementos interativos, navegação por teclado e estrutura semântica para facilitar o uso da aplicação.

## Versionamento

O projeto utiliza Git para controle de versões e GitHub para hospedagem do repositório.
